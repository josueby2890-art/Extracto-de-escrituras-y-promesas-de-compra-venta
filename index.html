Configuración ✓ guardada

Estos datos se guardan solo en tu navegador (localStorage). Necesitas una App Registration en Azure AD con permisos delegados Files.Read.All y Sites.Read.All, y tu URL de GitHub Pages registrada como SPA redirect URI.

OCR avanzado con Azure (opcional)
